# Онбординг нового пользователя: анимированная запись трека

Дата: 2026-06-03

## Проблема

Чтобы получить первый опыт работы с приложением, пользователю нужно физически
выйти на улицу и начать запись трека. Это откладывает знакомство с продуктом «на
потом», и непонятно, что в итоге пользователь получит. Нужен онбординг при первом
запуске: красивое анимированное демо записи трека + краткое объяснение, зачем
приложение нужно — прямо в помещении, без GPS-прогулки.

## Цель

Единый свайп-онбординг при первом запуске, который:
- показывает суть приложения (запись маршрута, оценка участков цветом, управление
  кнопками громкости) через анимацию прямо на экране;
- сохраняет существующее явное согласие с политикой конфиденциальности и условиями
  использования (важно для Google Play и фоновой геолокации);
- даёт доступ к политике/условиям из настроек.

## Решение (общая форма)

`FirstWelcomeFragment` остаётся хостом первого запуска. Внутри — `ViewPager2` из
4 страниц и закреплённая снизу панель навигации, общая для всех страниц.

Слайды:
1. **«Записывайте свои прогулки»** — анимация растущего цветного трека (акцент на
   самой записи маршрута).
2. **«Оценивайте маршрут на ходу»** — тот же приём + легенда цветов, акцент на
   смысле рейтингов.
3. **«Не доставая телефон»** — управление рейтингом кнопками громкости ↑/↓.
4. **Согласие** — существующий контент: чекбокс + кликабельный текст политики и
   условий.

Поведение нижней панели:
- Слайды 1–3: слева «Пропустить», по центру индикатор из 4 точек, справа «Далее».
- Слайд 4: «Пропустить» скрыт; правая кнопка — «Начать», активна только при
  поставленном чекбоксе (переиспользуем `WelcomeContinueButtonState`).
- «Пропустить» → `setCurrentItem(3)` (слайд согласия пропустить нельзя).
- «Начать» → существующая логика: `setWelcomeTutorialFinished(true)` +
  `onContinueListener` → `navigateTo(MAP_SCREEN)`.

## Архитектура и компоненты

### Хост: `FirstWelcomeFragment`
- Содержит `ViewPager2` + нижнюю панель навигации (точки, «Пропустить», основная
  кнопка).
- Подписывается на `ViewPager2.OnPageChangeCallback`: обновляет точки-индикатор,
  показывает/прячет «Пропустить», переключает подпись основной кнопки
  («Далее» ↔ «Начать»).
- На слайде согласия переносит существующую логику чекбокса/кликабельного текста
  политики (`PrivacyPolicyDialog` / `TermsOfUseDialog`).

### Адаптер: `WelcomeSlidesAdapter`
- `RecyclerView.Adapter` для `ViewPager2` (View-страницы, не фрагменты — кастомная
  анимация это обычная `View`, так проще).
- Два типа страниц:
  - **Tutorial-страница**: layout с `TrackRecordingAnimationView` + заголовок +
    подзаголовок; конфигурируется моделью `WelcomeSlide`.
  - **Consent-страница**: чекбокс + кликабельный текст политики/условий (контент
    из текущего `first_welcome_fragment.xml`).

### Модель: `WelcomeSlide`
- Описывает tutorial-слайд: режим анимации (`TrackAnimationMode`) + id строк
  заголовка/подзаголовка.

### Анимация: `TrackRecordingAnimationView`
- Кастомная `View`, рисование по `Canvas`, один `ValueAnimator`
  (прогресс `0f..1f`, режим `RESTART`, `invalidate()` на кадр).
- Режим задаётся сеттером/атрибутом `mode: TrackAnimationMode`:
  - **`RECORD`** (слайд 1): стилизованная ломаная из нормализованных точек
    (`0..1`, масштаб в `onSizeChanged`). По ней едет точка «я», за ней прорастает
    след до текущего прогресса. След окрашен **цветами рейтингов** (без
    `rating_none`), сегментов много — насыщенная дробная линия. Лёгкая
    стилизация фона под карту (пара блоков-«кварталов»).
  - **`RATE`** (слайд 2): тот же растущий след + маленькая легенда из 4 цветных
    меток (плохо/нормально/хорошо/отлично), акцент на смысле цветов.
  - **`VOLUME`** (слайд 3): трек + иконки кнопок громкости ↑/↓ сбоку; в такт
    анимации «нажимается» верхняя/нижняя кнопка, текущий сегмент перекрашивается
    (выше = лучше, ниже = хуже).
- Цвета берутся из существующих ресурсов: `rating_badly` `#EF434D`,
  `rating_normal` `#FFCC22`, `rating_good` `#008359`, `rating_perfect` `#00BF54`.

### Жизненный цикл анимации
- Старт — когда страница выбрана (`OnPageChangeCallback` / `onAttachedToWindow`).
- Стоп — когда страница уходит с экрана или `onPause`. Никаких работающих
  аниматоров в фоне (батарея).

### Чистый хелпер: `WelcomeTrackGeometry`
- Без зависимостей от Android Canvas.
- Логика: «прогресс → видимая длина следа», «позиция сегмента → `SegmentRating`».
- Чтобы избежать нюанса с `PointF` в JVM-тестах (конструктор no-op), внутри
  хелпера используется собственный простой тип точки (или `PointF().apply{...}`).
- Полностью покрывается JVM-тестами.

### ViewModel: `FirstWelcomeViewModel`
- Сохраняет существующую логику согласия и `onContinueListener`.
- Гейтинг кнопки «Начать» через существующий `WelcomeContinueButtonState`.
- Подпись основной кнопки («Далее» ↔ «Начать») — ответственность Fragment'а
  (зависит от текущей страницы, это UI-состояние).

### Настройки: доступ к политике/условиям
- В `fragment_settings.xml` — две строки-кнопки: «Политика конфиденциальности» и
  «Условия использования».
- В `SettingsFragment` — открытие существующих `PrivacyPolicyDialog` /
  `TermsOfUseDialog` (как сейчас в `FirstWelcomeFragment`). Заголовки
  `privacy_policy_title` / `terms_of_use_title` уже есть.

## Поток данных

1. `MainActivity` при старте: `isWelcomeTutorialFinished()` == false →
   `navigateTo(WELCOME_SCREEN)` (без изменений).
2. `FirstWelcomeFragment` показывает `ViewPager2`. Свайп/«Далее» листают слайды;
   при выборе страницы стартует её анимация.
3. На слайде 4 чекбокс согласия → `FirstWelcomeViewModel` обновляет
   `WelcomeContinueButtonState` → активность кнопки «Начать».
4. «Начать» → `setWelcomeTutorialFinished(true)` + `onContinueListener` →
   `navigateTo(MAP_SCREEN)` (логика без изменений).
5. Позже из настроек пользователь может открыть политику/условия.

## Обработка краевых случаев

- Поворот экрана: текущая страница пейджера восстанавливается стандартно;
  состояние чекбокса/кнопки — из ViewModel. Анимация перезапускается с прогресса
  заново (визуально допустимо).
- Уход в фон: анимация останавливается, при возврате — продолжает с текущей
  страницы.
- «Пропустить» не обходит согласие: перематывает на слайд 4, согласие
  по-прежнему обязательно.

## Локализация

- Новые строки: заголовки/подзаголовки слайдов 1–3, «Далее», «Пропустить»,
  «Начать», метки легенды, названия пунктов настроек.
- Кладём и в `values/` (en), и в `values-ru/` (ru).

## Тестирование

- `WelcomeTrackGeometryTest` (JVM): прогресс → видимая длина следа; индекс
  сегмента → `SegmentRating`; границы `0f` и `1f`.
- `FirstWelcomeViewModelTest` (JVM): кнопка «Начать» неактивна без чекбокса,
  активируется при чекбоксе; `setWelcomeTutorialFinished(true)` и
  `onContinueListener` вызываются только при согласии.
- Конвенции тестов: SUT зовётся `sut`, `@Before`/`@After`, тела разбиты на
  given/when/then.

## Вне области (YAGNI)

- `WelcomeTutorialStep` (persist-перечисление) не трогаем.
- Слайд «чужие маршруты» не добавляем (договорились о 4 слайдах).
- Lottie/Compose не подключаем — только кастомный Canvas-View.
